Datacenter solution · end to end

One Datacenter solution, built on the platform modules we already run

Datacenter Ops is a module of the Opstral Ops Toolkit. Plan & Build and Operations screens read their records from the platform's own modules (Inventory, IP Management, Supply chain, BSS, ITSM) and write back through them. This map shows every module the solution uses, what it gives each Datacenter screen and what Datacenter sends back. Where both had the same function, the platform module owns the record.

Who owns what

Where the platform and the Datacenter ideation had the same function, the platform module is the system of record. Datacenter screens read it and raise records in it; they never keep a second copy.

How a Datacenter screen reaches a module

Screens never call a module directly. They call one API layer, app/src/api/index.ts; each function there names its future REST path. Integrating a module means pointing those functions at the module's API and mapping its fields onto the contract types. The screens do not change.
